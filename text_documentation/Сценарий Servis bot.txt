#1.1 Критическое уведомление:
# Находится в отделе А (критические ситуации)
# Зона не требуется.
# Тип: [нет света, нет воды, нет интернета, проверка гос органов]
# Приоритет. Автоматически критический
# Путь: критические ситуации - тип
# Уточнение:
# иногда необходимо.
# Комментарий необязателен
# Подтверждение необходимо
# Статус.Создана/закрыта. Отправка уведомления, что ситуация случилась и закончилась
# Эскалации нет

#1.2 Критическая заявка:
# Это заявка которую нужно решить в ближайшее время.
# Зона необходима.
# Тип необходимо указать.
# Путь:
# Отдел - зона - тип
# Комментарий необязателен
# Уточнение необходимо чтоб точнее выставить статус
# Если статус крит - то автоматически передаём в работу
# Если статус высокий - то отправляем на подтверждение упр (молоко почти кончилось, но еще есть. Статус высокий)
#  Статусы
# - создана
# - в работе (ставит отдел)
# - ожидание
# - выполнено
# - закрыта (управляющий)
# - SLA реакции: 15 минут
# - SLA выполнения: N часов
# Эскалация:
# Если выполнение невозможно → отклонено + коммент → уведомление руководству

#2. Срочная заявка.
# Заявка которую нужно решить в течении дня.
# Зона необходима.
# Тип необходимо указать.
# Путь:
# Отдел - зона - тип
# Уточнение и комментарий необязательны
# Всегда ожидаем подтвержения упр
# Приоритет высокий
#  Статусы
# - создана
# - в работе (ставит отдел)
# - ожидание
# - выполнено
# - закрыта (управляющий)
# - SLA реакции: 2 часа
# - SLA выполнения: до конца дня
# Эскалация:
# Если выполнение невозможно → отклонено + коммент → уведомление руководству

#3. Обычная заявка.
# Заявка которую нужно решить в течении пары дней.
# Зона необходима.
# Тип необходимо указать.
# Путь:
# Отдел - зона - тип
# Уточнение и комментарий необязательны
# Всегда ожидаем подтвержения упр
# Приоритет средний
#  Статусы
# - создана
# - в работе (ставит отдел)
# - ожидание
# - выполнено

# - SLA реакции: 1 день

# - Эскалация: только при отклонении

# Путь - отдел - заявка

#5. Уведомление.
# Сообщение о событии отделу.
# Отдел - обязательно.(HR, бухгалтер, сервис)
# Зона и тип не нужны.
# Комментарий обязателен
# Подтверждение при отправке необходимо
# Подтверждение упра не нужно
# Сообщение отправляется упр и отделу
# Статус отправлено. Встаёт в этот статус при отправке и не требует изменения

# Подтверждение упр: необязательно
# Сообщение отправляется упр и отделу
